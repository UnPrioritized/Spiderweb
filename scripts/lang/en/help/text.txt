Click on the piano roll and type (Enter = new line, Esc = done). The letters become a custom shape, so they can be filled, moved, resized, turned and skewed.

The text's notes start right where you clicked (with Align Left), and its lowest note sits on the key you clicked (a letter with a tail, like "g", reaches down to it and lifts the rest). It stays there while you type or change settings; move the text to give it a new spot.

Panel: font, size (font size, or rows = how many keys tall the capital letters are), weight and italic, plus:

Letter spacing: extra room between the letters, in 1/1000 of the font size. Minus numbers pull them closer together.
[clip:text-letterspace]

Line spacing: room between lines (Enter starts a new line), in % of the font's own line spacing.
[clip:text-linespace]

Align: where the text sits on the spot you clicked. Left = its first note starts there, Centre = its middle is there, Right = its last note ends there. With several lines it also lines them up. In the player directions Align works across the keys instead (see below), and the first note always starts at the click.

Direction: which way the letters go.
- Piano roll: along time, so the text reads normally here.
- Player across: the text reads across the keys in a falling-notes player. Each new line arrives before the one above it. Align puts the lowest note (Left), the middle or the highest note (Right) on the key you clicked.
- Player down: the letters arrive one after another in steady steps, first letter first. Letter spacing adds or takes away time between them. Each new line becomes a column beside the first (higher keys), arriving at the same time. Align lines the letters up on the column's low keys, centre or high keys, and puts the lowest note, the middle or the highest note on the key you clicked.

Letters that would go past the highest key are cut off, never squeezed.

Letter turn and Flip letters: turn each letter on its own spot (Flip turns it upside down first). The player directions set them to 90 and ticked, which stands the letters upright in a player; you can change them after, for example to 45.
[clip:text-align]

Text is a custom shape, so Empty, Fill, Spam and Outline spam work on its letters too (see Inside fill).
[clip:text-inside]

Threshold (Fill / Spam): how much of a key's height has to be inside a letter for that key to play there. 50% = the key's middle. Lower = chunkier letters, higher = thinner.
[clip:text-threshold]

Grow: makes the letters' strokes thicker, in keys (minus = thinner). Big values can look odd in tight corners.
[clip:text-grow]

Spam text can be a Hz bass too: one tone for all the letters, and the text keeps its own length (see Hz bass).

Letters the font doesn't have are taken from another font. If no font on the PC has a letter, the status line says so.

Click a text with the Text tool (or double-click it with Select, or right-click → Edit text) to retype it. Drag, Shift+arrows, double-click (a word) or Ctrl+A select letters; Ctrl+C / X / V copy, cut and paste them (with no letters selected, Ctrl+C copies the whole shape).

Right-click → Split into letters: every letter becomes its own text, right where it was, with the same notes (spaces go). If letters overlap, or the text has Claw, Chop or a Gate range (they then work on each letter alone), some notes change and the status line says so. All of them stay selected, so you can move, turn or flip each one, or click one to retype it.

Right-click → Turn into custom shape: the text becomes a normal custom shape, so you can edit its lines and use everything custom shapes have. It can't be retyped after that. Its notes can move a little: a custom shape fills a key wherever any of it is inside, so Fill and Spam come out a bit chunkier (like Threshold 0%), and Grow is kept in its lines.
