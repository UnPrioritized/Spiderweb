Tools: V Select, K Slice, L Line, P Polyline, F Freehand, C Curve, A Arc, S Custom shape, O Circle, Q Polygon, N Funnel, X Text, H Hz bass, I Image. G = Live shape on / off. M = Mask on / off.

Drawing: Shift = don't snap. Ctrl = perfect (circle, equal-sided polygon or star, proportions). Esc = cancel what's half drawn. Enter, double-click or right-click = finish a polyline (right-click drops an unfinished arc or a shape started with a click).

Mouse: right-click a shape = its menu, empty space = deselect. Right-click a curve's anchor, a funnel's point or a picked stroke's point = remove it. Double right-click = Select ↔ last tool. Right-drag = listen. Middle-click = add a point / anchor / funnel curve start. Middle-drag = scroll.

Select: click a selected shape again = the next shape under it. Ctrl+drag after a box = another box; Ctrl+drag inside the box = move a copy.

Wheel = scroll, Shift+wheel = sideways, Ctrl+wheel = zoom, Ctrl+Shift+wheel = zoom time, Alt+wheel = zoom pitch.

Editing: Del delete, Ctrl+D duplicate, Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) undo / redo (see History), Ctrl+A select all, Ctrl+C / Ctrl+X / Ctrl+V copy / cut / paste, Ctrl+H / Ctrl+J flip, Ctrl+Left / Ctrl+Right turn 90°, Ctrl+G join into one curve, Ctrl+Shift+G split into separate shapes, Ctrl+R turn into live shape, Alt+W claw machine, Alt+S strum, Alt+U chop, Ctrl+U quick chop, Esc clear highlight / unpick a stroke. With a stroke of a live shape picked, the copy / paste / flip / turn keys work on that stroke.

Playing: Space play / stop. Click the bar numbers = move the play line. Drag along them = select every key in that time.

Curves: Alt+drag a handle = sharp corner, Alt+drag an anchor = new handles, Ctrl = change only this curve (linked funnel curves).

Number boxes: drag the name, Up / Down, wheel after a click; Shift = big steps, Ctrl = small.

F1 = Help. Ctrl+S = save. Ctrl+Shift+C = Copy to Domino (notes copied in Domino paste with Ctrl+V).

The drawer and the Hz bass window have keys of their own: see their pages.
