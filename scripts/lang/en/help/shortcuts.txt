Tools: V [page:select|Select], K [page:slice|Slice], J [page:lasso|Lasso], L [page:line|Line], P [page:poly|Polyline], F [page:free|Freehand], C [page:curve|Curve], A [page:arc|Arc], S [page:custom|Custom shape], O [page:box|Circle], Q Polygon, N [page:funnel|Funnel], X [page:text|Text], H [page:hz_bass|Hz bass], I [page:picture|Image]. G = [page:live|Live shape] on / off. M = [page:masks|Mask] on / off.

Drawing: Shift = don't snap. Ctrl = perfect (circle, equal-sided polygon or star, proportions). Esc = cancel what's half drawn. Enter, double-click or right-click = finish a polyline (right-click drops an unfinished arc or a shape started with a click).

Mouse: right-click a shape = its menu, empty space = deselect. Right-click a curve's anchor, a funnel's point or a picked stroke's point = remove it. Double right-click = Select ↔ last tool. Right-drag = listen. Middle-click = add a point / anchor / funnel curve start. Middle-drag = scroll.

Select: click a selected shape again = the next shape under it. Ctrl+drag after a box = another box; Ctrl+drag inside the box = move a copy.

Wheel = scroll, Shift+wheel = sideways, Ctrl+wheel = next / previous track, Ctrl+Alt+wheel = zoom, Ctrl+Shift+wheel = zoom time, Alt+wheel = zoom pitch.

Editing: Del delete, Ctrl+D duplicate, Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) [page:undo|undo / redo] (see [page:history|History]), Ctrl+A select all, Ctrl+C / Ctrl+X / Ctrl+V copy / cut / paste, Ctrl+H / Ctrl+J flip, Ctrl+Left / Ctrl+Right turn 90°, Ctrl+G [page:join|join into one curve], Ctrl+Shift+G split into separate shapes, Ctrl+R [page:turn_live|turn into live shape], Alt+W [page:claw|claw machine], Alt+S [page:strum|strum], Alt+U [page:chop|chop], Ctrl+U quick chop, Alt+Enter [page:properties|Properties], Esc clear highlight / unpick a stroke. With a stroke of a live shape picked, the copy / paste / flip / turn keys work on that stroke.

Hold W = see the piano roll as it will be exported (with Keep notes made there and Wrap them around on; see [page:offrange|Notes past the keys]).

Playing: Space play / stop. Click the bar numbers = move the play line. Drag along them = select every key in that time.

Curves: Alt+drag a handle = sharp corner, Alt+drag an anchor = new handles, Ctrl = change only this curve (linked funnel curves).

[page:numbers|Number boxes]: drag the name, Up / Down, wheel after a click; Shift = big steps, Ctrl = small.

Tab = the piano roll ↔ the track list (see [page:tracks|Track list]).

Typing a text: Ctrl+Left / Ctrl+Right jump a word, Ctrl+Backspace / Ctrl+Delete erase one (see [page:text|Text]).

F1 = Help. Ctrl+S = save. Ctrl+, = [page:settings|Settings]. Ctrl+Shift+C = [page:domino|Copy to Domino] (notes copied in Domino paste with Ctrl+V).

The [page:drawer|drawer] and the Hz bass window have keys of their own: see their pages.
