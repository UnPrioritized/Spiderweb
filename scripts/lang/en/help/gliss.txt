## Drawing a run

A run of short notes. Drag a line from where the run starts to where it ends: each picked key between them gets one note, one grid step long, one after another.

The step picks itself: the grid nearest one key per step for the line you drew. A steeper line = a finer grid. When you let go, the line's end moves to where the last key's note starts.

The side panel's Grids picks which grid sizes the step can be: Halves (1/1, 1/2, 1/4 … as fine as the PPQ allows) or My list, your own sizes like 1/16, 1/32, 1/48, 1/256. Grids shorter than one tick are skipped: a higher PPQ allows finer grids.

## Picking keys

While the Glissando tool is in use, or a run is selected, click the piano keys on the left to pick which keys the run plays. Picked keys light up blue, and each click plays the key so you can hear it.

A click picks that note in every octave: click C, E and G for a C major run. Click a lit key again to unpick that note in every octave. Ctrl+click picks or unpicks just that one key.

With a run selected, the picked keys are the run's: pick other keys and the run follows them. With nothing selected, they are the keys your next runs use. With no keys picked, runs use the white keys.

## Moving a run's ends

Select a run and drag its squares to move its ends.
