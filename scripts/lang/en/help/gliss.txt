## Drawing a run

A run of short notes. Drag a line from where the run starts to where it ends: each picked key between them gets one note, one grid step long, one after another.

The step picks itself: the grid nearest one key per step for the line you drew. A steeper line = a finer grid.

The side panel's Grids picks which grid sizes the step can be: Halves (1/1, 1/2, 1/4 … as fine as the PPQ allows) or My list, your own sizes like 1/16, 1/32, 1/48, 1/256. Grids shorter than one tick are skipped: a higher PPQ allows finer grids.

## Picking keys

While the Glissando tool is in use, or a run is selected, click the piano keys on the left to pick which keys the run plays. Picked keys light up blue, and each click plays the key so you can hear it.

A click picks that note in every octave: click C, E and G for a C major run. Click a lit key again to unpick that note in every octave. Ctrl+click picks or unpicks just that one key. Hold the button and move up or down to hear other keys: the key you let go on is the one picked.

With a run selected, the picked keys are the run's: pick other keys and the run follows them. With nothing selected, they are the keys your next runs use. With no keys picked, runs use the white keys.

## Changing a run

The line stays where you draw it. Select a run and drag its squares to move its ends. Changing Grids, Step, Copies, Note length or Last note moves the end onto the notes: where the last note ends, or where it starts with "Last note: starts exactly on the last point".

Step: Auto picks the step from how steep the line is. Pick a fixed step to make the run faster or slower: 1/32 to 1/64 makes it 2x faster. The run keeps its start and keys and gets shorter or longer.

Copies: copies of the run above and below it, each one picked key further out, playing at the same times. On the piano roll, a selected run has a dotted line above it and one below: drag them up or down.

Note length: how long each note is, as % of the step (100 % = up to the next note, more = they overlap) or in ticks. On the piano roll, drag any note's right end: every note in the run follows.
