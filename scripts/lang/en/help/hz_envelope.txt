An effect can also start at each note, like an envelope: in the Repeat every… window, set Plays to Once per note (All the way, the first choice, = the line runs over the whole shape, repeating, whatever the notes do). Its line then plays once from the start of every note, for as long as Lasts says, and stays on its last value until the note ends.

Restart at each note repeats it but starts it over at every note. Tick Stretch to each note to make it last as long as each note instead.

Each note has its own, as in a synth: a note added on top of another starts its effects over alone. A note reached by a slide carries on, it doesn't start again.

Right-click → Shape → Drop, Rise or Pluck gives a ready-made one (pitch: falls from the top of its Range, rises from the bottom (12 keys up / down to start with), or a quick bump up).

Changes faster than about half a beat at 120 BPM are hard to hear: the tone only changes once per wave. Volume sounds about the same in its top half (a rendered file is usually already as loud as it gets there), so a fade is heard mostly near 0 %.

A line that plays once per note (with Stretch to each note unticked) can have a sustain point, like a synth's envelope: right-click one of its points → Sustain here until the note ends (it turns into a diamond). The line plays up to that point, stays there for as long as the note lasts, and the rest of it (the fall) plays after the note ends.

The note keeps sounding during the fall, even under the notes after it (both sound there, like a chord), unless a note of the same tone starts. A slide doesn't end the note.

A note that ends before reaching the sustain point falls from wherever it got to. The dashed lines show where each fall starts.
