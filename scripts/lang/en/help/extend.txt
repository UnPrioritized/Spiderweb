Select one or more shapes, then right-click one: Gate extend… Every note ends a little later, so it runs over into the notes after it, like a run played by hand. Notes keep their starts, keys, colours and velocities.
[clip:extend-amount]

A run as drawn, and with Gate extend at 100 %: every note twice as long, running over the next ones.

## The amount

Amount in: % of each note's length (the default) or Ticks. With 50 %, a note of 10 ticks ends 5 ticks later and a note of 40 ticks 20 ticks later, so short notes stay short. With Ticks every note ends the same number of ticks later. Switching keeps the numbers shown.

Add: how much each note gets (0 = none). Drag the box or the word beside it sideways to change the number. In ticks, the number follows the PPQ, so changing the PPQ keeps the look.

A note never runs into the next note on its own key: it stops where that one starts (two notes on one key at once clash in any MIDI player). Notes on other keys overlap freely.

## Change across the shape

Tick Change across the shape to make the amount change from the first number to the second along a graph, for example short at the start of a run and long at its end. It works like Gate subtract's graph: Left to right, Low to high or Top to bottom, Each key row by itself, and ready-made graphs under it.
[clip:extend-vary]

Left to right from 0 % to 300 %: the run's first notes stay as they were, its last ones run far over.

## Using the window

Changes show on the piano roll at once, and the window follows the selection. OK keeps the changes as one undo step, Cancel or Esc puts back what changed, Ctrl+Z steps back through the changes made in the window.

The menu item has a tick while a selected shape has it, and the Shapes list says (Extended). Untick Add to gates in the window to take it off.

## With other features

Gate extend comes after everything else that makes the notes, Sustain too, and before Gate subtract: a shape with both gets its gaps cut from the longer notes.

Flipping or turning the shape moves the graph with it. Slicing and splitting keep it on every piece, with the graph cut so every note keeps its amount. Join, Turn into live shape and Gate sensitive merge keep it when all the shapes have the same settings. An Add between group gets it step by step when both ends have it in the same unit.

Turn into plain notes, Apply mask copies and mask areas are made without it. A Hz bass and an image can't have it.

On a shape with Recolour (Stir, Shuffle, Per chord, Clumps...) or Liquify, this can also change the colours of notes elsewhere in the shape, because those colours depend on the notes around them. In Single channel that can also change where overlapping notes end. To keep the colours as they are, use Turn into plain notes first.
