Select one or more shapes, then right-click one: Gate extend… Every note ends a little later, so it runs over into the notes after it, like a run played by hand. Notes keep their starts, keys, colours and velocities.
[clip:extend-amount]

A run as drawn, and with Gate extend at 100 %: every note twice as long, running over the next ones.

## The amount

Add: how much each note gets (0 = none). What you type decides the unit:
• 120 = 120 ticks: every note ends the same number of ticks later.
• 50% = half of each note's own length: a note of 10 ticks ends 5 ticks later, a note of 40 ticks 20 ticks later, so short notes stay short.
• 50% + 10 = both: half of each note's length and 10 ticks more.
• Math works too: 960*2, (50% + 10) * 2. A % can be added to ticks or multiplied / divided by a number; 50% * 50% can't be used (the box turns red and says why).

Amount in shows what the box holds: Ticks, % of each note's length, or "% + ticks" when it has both. Picking Ticks or % there turns every number into that unit (50% + 10 becomes 60 ticks, or 60%). The mouse wheel, Up / Down and dragging the box or the word beside it change the last number in the box. Ticks follow the PPQ, so changing the PPQ keeps the look.

Same amount for every note (when there's a %): every note gets the same number of ticks, worked out from the shape's average note length. Use it on a slanted line whose notes differ by a tick: the ends then follow the starts as evenly as with ticks. Leave it off for shapes whose notes really are different lengths.

A note never runs into the next note on its own key: it stops where that one starts (two notes on one key at once clash in any MIDI player). Notes on other keys overlap freely.

## Change across the shape

Tick Change across the shape to make the amount change from the first number to the second along a graph, for example short at the start of a run and long at its end. It works like [page:subtract|Gate subtract]'s graph: Left to right, Low to high or Top to bottom, Each key row by itself, and ready-made graphs under it.
[clip:extend-vary]

Left to right from 0 % to 300 %: the run's first notes stay as they were, its last ones run far over.

The two numbers can be different kinds, for example from 10 (ticks) to 50%: each note gets its own mix of both along the graph.

## Using the window

Changes show on the piano roll at once, and the window follows the selection. OK keeps the changes as one undo step, Cancel or Esc puts back what changed, Ctrl+Z steps back through the changes made in the window.

The menu item has a tick while a selected shape has it, and the [page:shapes|Shapes list] says (Extended). Untick Add to gates in the window to take it off.

## Your own default

The pin left of OK saves the window's settings as what shapes start with when they get Gate extend (instead of 50%). Click it: Save current as default, or Forget my default. Black and leaning = none of yours saved, green and pointing down = saved. Shapes that already have Gate extend keep their own settings. Every saved default is listed in [page:settings#User set defaults|Settings → User set defaults].

## With other features

At first Gate extend comes after everything else that makes the notes, [page:sustain|Sustain] too, and before Gate subtract: a shape with both gets its gaps cut from the longer notes. [page:properties|Properties] can move it anywhere.

Flipping or turning the shape moves the graph with it. Slicing and splitting keep it on every piece, with the graph cut so every note keeps its amount. [page:join|Join], [page:turn_live|Turn into live shape] and [page:merge|Gate sensitive merge] keep it when all the shapes have the same settings. An [page:between|Add between] group gets it step by step when both ends have it in the same unit.

Turn into plain notes, Apply mask copies and mask areas are made without it. A [page:hz_bass|Hz bass] and an image can't have it.

On a shape with [page:recolour|Recolour] ([page:stir|Stir], Shuffle, Per chord, Clumps...), [page:warp|Warp] or [page:liquify|Liquify], this can also change the colours of notes elsewhere in the shape, because those colours depend on the notes around them. In Single channel that can also change where overlapping notes end. To keep the colours as they are, use Turn into plain notes first.
