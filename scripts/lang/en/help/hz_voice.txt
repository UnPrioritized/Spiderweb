Voice (in the OSC tab of the synth window): Voices = how many copies of the sound play together, Detune = how far out of tune they are with each other (in cents, 100 = one key), Blend = how loud the middle copies are next to the outer ones (50 % = all as loud), Random start = each copy starts its wave at a random point at every new note.

Voices on = whether the keys take turns playing them (Split keys, no extra notes) or every key plays all of them (Same keys, more notes).

Glide = each note slides in from the tone of the note before it, taking that long (Only notes that touch: only when it starts right where that note ends). Curve = how it slides: middle = straight, right = fast first then settling (the classic bass slide), left = slow first.

Legato = a note that starts right where another ends carries on from it as one long note: no new Attack, and no Release until the last one ends (the effects that play once per note go on too). It works on the Arpeggio's notes as well: at Gate 100 % the whole run gets one envelope, under 100 % each note starts over.

The picture shows which copies eight keys play and a glide. Voice is a setting of its own, not a line.

Arpeggio (the third row of the OSC tab): switched on (click the light or the name on its header), every note you placed is played as a fast run of short notes, as a synth's arpeggiator does.

Pattern = the order (Up, Down, Up and down, Random).
Speed = notes a beat.
Octaves = how many octaves the run climbs through.
Gate = how long each note is (100 % = touching).
Swing = the notes between the steps of the beat grid come late, for a bouncy groove.
Chord = which notes. Notes held runs through every note held: a note added while the run goes joins it at its next step, as on a synth, and once nothing is held the run ends. The others add a chord's notes to every note.
Scale + Root = every note of the run moves to the nearest note of that scale, so it stays in key.

Pattern Steps = your own steps, played in a loop. A grid shows up under the picture: one column for each step. Pick a lane over the grid, then click or drag across the columns. Middle-click a step = that lane back to its start.

The lanes: Note = which held note the step plays (1 = the lowest, 2 = the next… if fewer are held, it counts round again from the lowest; Rest = silence), Octave = moves it up or down, Loudness = how loud, Length = how long (times Gate), and Tie at the top = the note lasts on through the next step.

The Steps box beside it = how many steps play (1 to 16); the ones past it are kept, greyed, for when you make it bigger again. With Octaves above 1, the steps are played again one octave higher each time round.

Each note of the run is a note of its own, so the Volume envelope and Glide work on each. Slides you made are left out while it's on. Like Voice, it's a setting of its own, not a line.
