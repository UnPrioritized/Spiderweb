Under Project → Channels:

As drawn: every note exactly as the shapes make it, one channel; notes on the same key may overlap.

Single channel: where two notes on the same key overlap, the earlier one is cut where the later starts and the later one is stretched to where the earlier would have ended; notes starting on the same tick become one (the loudest, as long as the longest).

Split around instead of stretching, under Single channel: the later note still wins, but it keeps its own length, and what's left of the earlier note after it comes back as a note of its own. More notes, and the gaps look even. Saved with the project.

Multi channel: shapes whose notes clash go on different channels, each on its own track (channel 10, drums, is skipped). "Split: same key at the same time" = only notes on the same key at the same time clash; "Split: any notes at the same time" = any notes at the same time. Shapes that follow one after another share a channel.

Remove overlaps, under Multi channel: shapes still get their own channels and colours, and on top of that no two notes sound on the same key at once, so no MIDI player cuts them at random. The track order decides who wins, as the [page:tracks|track list] shows it (your own tracks where they're listed; Reverse track order turns it round too):
• Earlier tracks win (the usual): a note on a track higher up in the list cuts the overlapping notes of the tracks below it. A note lying wholly under a winner is gone; the shape list then says "0 notes (all overlapped)".
• Later tracks win: the other way round.
The losing note is split around the winner: cut where it starts, and what's left after the winner ends comes back as a note of its own. Tick "Cut + stretch like Single channel" to only cut it and stretch the winner over the rest instead. Pieces as short as 1 tick are kept. Overlaps inside one track are fixed first, like Single channel. Notes pasted from [page:domino|Domino] take part too; [page:sustain|Sustain] shapes keep their overlaps, and a loaded MIDI is never changed. [page:companion|Draw on Domino] does the same with the notes already in Domino's tracks. Saved with the project.

Use channel 10 (16 colours), under Multi channel: channel 10 is used too, so there are 16 colours instead of 15 (a shape, Colours and the drawer's areas can then have 16). Many synths play channel 10 as drums. With a piano-only soundfont, many MIDI players stay silent there and only show the notes' colour. Built-in BASSMIDI plays it as a piano. Saved with the project.

Channels 1-16 in order, under Use channel 10: shapes take channels 1, 2, 3 … 16 in order, so a shape's 10th colour goes on channel 10. Off, channel 10 comes last (1-9, 11-16, then 10), so ticking Use channel 10 changes no colour. When 10 or more channels are in use, the 10th and later change colour when this is switched, because each channel keeps its own colour. Saved with the project.

Repeated colours get new channels, under Multi channel: when a shape's colours start again from the first colour, the repeated colours go on new channels with the same colours (15 channels further on, 16 with Use channel 10). A channel never holds a colour twice, so in other programs each repeat is its own track and can be edited on its own. It counts for every colour that starts again: Colours, the rings of a [page:nested_tiles|Nested fill], the tiles of a Tiles fill, the steps of an [page:between|Add between] group (the whole group together) and the copies of [page:path|Copy along a path]. Area colours and outline colours count too: when one colour is used on parts of a shape that don't touch (or on both shapes of a merged shape), the first part keeps the channel and each other part is a repeat; a colour used once stays. Other shapes keep the first channels; the repeats come after them, shape by shape in the shape list's order. Saved with the project.

Keep empty tracks, under it (on to start): each time the colours repeat, all 15 channels (16 with Use channel 10) get a track in the MIDI file and Export to Domino, empty ones too, so every repeat takes the same number of tracks (the last repeat stops at its last channel used). It works the same with [page:settings|Settings] → Note colours → Overlapping shapes keep their colours. Untick it to write only the tracks that have notes. Every note keeps its channel and colour either way.

Some shapes can spread over several channels: pasted notes (by track), images (by their colour list), merged shapes (each part keeps its own colours), live shapes made with [page:turn_live|Turn into live shape] (by the shape each stroke came from), [page:fill|Fill] / Spam set to Outline (the outline and the inside), Nested, Tiles and [page:ripples|Ripples] (each step, tile or ring), Add between (each shape of the group) and Copy along a path (its Colours choice). The [page:shapes|shape list] says how many. Above 15 (16 with Use channel 10) it shows in orange, and from there the colours and channel numbers repeat.

Every channel has its own note colour (Settings → Note colours).

Colours (in the side panel, under Velocity): any shape's notes take turns over several channels, so its colour keeps changing. It needs Multi channel. Which colours you see depends on the program showing the MIDI.

By step = each step the next channel (spam: each gate column; lines: each note in time), By key = each key, By time = every note length from the start of the song (1/4 = a beat, so it lines up with the bar lines). Channels = how many take turns, every = how long one lasts.

Each key row (By step / By time, Spam and Outline spam shapes only): From its start = each key row starts again at the first channel where its notes begin (after a gap too), so the colours follow the shape's left edge; From its end = counted back from each row's last note, so they follow the right edge.

Diagonal (By step / By time): [n] channels every [m] keys = every m keys up from the shape's lowest key, the turns start n channels later, so each colour runs as a slanted line through the shape. 0 = off, a minus number slants the other way. Mix it with Each key row and the every box to find a look you like.
